Which option fits my POS?

Toast: set up a "Dinner Club 2-for-1" discount (lowest-priced item). The simplest fit is usually No code or Promo code. Confirm with Toast before relying on a scanned coupon.


Square: create a discount, then choose Barcode or Promo code if your register has a scanner.


Clover, Lightspeed, SpotOn and others: if your POS printed a coupon barcode, use Upload a graphic. Otherwise use Promo code.
